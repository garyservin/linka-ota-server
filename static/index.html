Your browser can't talk to USB serial devices. Open this page in Google Chrome or Microsoft Edge on a computer. Flashing only works on pages served over HTTPS (or from localhost).
Keep the sensor on devel: after installing, open the sensor's setup page and set Server for OTA upgrades to the address below. Otherwise it goes back to the production version at its next update check.

How it works

  1. Plug the sensor into this computer with a USB data cable (some cables only charge).
  2. Click Connect & install, pick the sensor's serial port and confirm. Erasing the device gives a clean install, but also clears its Wi-Fi and settings.
  3. When it finishes, the sensor restarts and opens its own Wi-Fi network. Connect to it to set your Wi-Fi, the sensor's location and its API key.
  4. From then on the sensor checks for updates once a day and installs them by itself.

If flashing fails, unplug the sensor, plug it back in and try again.
