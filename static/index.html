Linka Firmware Flasher

Install the firmware of your Linka air quality sensor straight from the browser.

1. Choose a version

Firmware track

2. Connect the sensor and install

Your browser can't talk to USB serial devices. Open this page in Google Chrome or Microsoft Edge on a computer. Flashing only works on pages served over HTTPS (or from localhost).
Keep the sensor on devel: step 3 sets this up for you. If you set the sensor up from its own Wi-Fi network instead, set Server for OTA upgrades to the address below, or it goes back to the production version at its next update check.

3. Set up the sensor

Send the settings over the same USB cable, so the sensor starts working right away. Close the installer window first. Fields left empty keep the sensor's current value, so this also changes the settings of an installed sensor.
